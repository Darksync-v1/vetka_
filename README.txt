Сборка:
1. Установи JDK 21 и Gradle 8.8+ (или скопируй папку gradle/ и gradlew из https://github.com/FabricMC/fabric-example-mod).
2. В папке проекта:  gradle build      (или ./gradlew build)
3. Готовый мод: build/libs/vetka-v1-1.0.0.jar -> положи в .minecraft/mods вместе с Fabric API.
Меню: Right Shift.
