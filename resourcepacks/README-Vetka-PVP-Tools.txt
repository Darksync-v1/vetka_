Vetka PVP Tools
================

Bundled from the supplied PVP-tools 1.16.5 pack and updated to resource pack format 34 for Minecraft 1.21.1.

The PVPTools module in the Render category installs and enables this pack when turned on, and disables it when turned off.

It replaces item textures for swords, axes, pickaxes, shovels, hoes, bows, crossbows, trident, fishing rod, spyglass, mace, buckets and other utility items included in the source pack.

This is a separate pack from Vetka-Totem-Animation, so both can be enabled together. If another active resource pack overrides the same item textures, Minecraft's resource-pack priority determines which texture is visible.
